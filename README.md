# 马原刷题包 · 第二阶段

自考《马克思主义基本原理》（课程代码 **15044**，原 03709）备考 App 的第二阶段，接第一阶段「认知包」之后使用。

目标：**把 50 分的选择题打到 34 分以上。**

- 包名：`com.study.mayuan2`（与第一阶段不冲突，可同时装）
- 应用名：马原刷题包
- 完全离线，不申请任何权限
- 进度与错题本自动保存

---

## 结构：七天，七个板块，84 道真题

沿用「方法在前、刷题在后」的模式。每天打开先看三张方法卡，再刷 12 道题。每天约 15 分钟。

| 天 | 板块 | 三张方法卡讲什么 |
|---|---|---|
| 一 | 绪论与唯物论 | 限定词定位法 / 缩小范围型干扰项 / 来源与前提之分 |
| 二 | 辩证法与哲学派别 | 总特征与核心之分 / 三条规律口诀 / 五对范畴各管一件事 |
| 三 | 认识论与真理 | 认识论四象限 / 感性理性六个词 / 经验主义与教条主义 |
| 四 | 唯物史观 | 「决定」与「影响」两个档位 / 两对关系别串门 / 看清「社会」二字 |
| 五 | 商品与价值 | 三组「二」对应线 / 固定动词 / 正反比方向 |
| 六 | 剩余价值与资本 | 两把尺子量同一笔资本 / 三种剩余价值判别词 / 分母决定名称 |
| 七 | 垄断与科学社会主义 | 垄断组织松紧序列 / 金融寡头两条线 / 科社「第一次」清单 |

每题作答后立即给出对错、解析和真题出处。

## 错题本

答错的题自动进错题本，**答对一次就自动移出**。首页显示当前错题数和按板块分布。七天刷完后集中重刷错题，刷到清空为止。

跨天累积，重刷时不区分是哪天错的。

---

## 题目来源

84 道题全部取自 2017—2026 年历年真题，答案以官方参考答案或试卷内标注为准。其中 2025 年 10 月、2026 年 4 月两套是新课程代码 15044 的卷子，优先选入。

每题的解析为针对该题辨析点手写，指向「为什么其他三项不对」，而不是复述知识点。

## 怎么出 APK

1. 新建 GitHub 仓库，把本目录所有文件推上去（保持目录结构）。
2. Actions 自动构建；也可在 Actions 页面手动 **Build APK → Run workflow**。
3. 约 3～5 分钟后，在运行页底部 **Artifacts** 下载 `mayuan-stage2-apk`。
4. 解压得到 `马原刷题包-v1.apk`。

构建环境：JDK 17 + Gradle 8.7 + AGP 8.4，minSdk 26（Android 8.0 以上）。

debug 包每次构建签名不同，**更新版本要先卸载再装**。

## 改内容

全部题目、解析、方法卡都在 `app/src/main/assets/index.html` 里：`DAYS` 数组即全部数据，每天一个对象，`tips` 是方法卡，`qs` 是题目（`q` 题干 / `o` 四个选项 / `a` 正确答案下标 / `w` 解析 / `s` 出处）。

改完直接推送即可重新出包。
